工具範圍

Agent 課程發布助手是由 GitHub 使用者 chenne0819 維護的個人用途本機工具，用於連接自己管理的 YouTube 頻道及準備課程影片發布流程。此說明網站不提供公眾註冊或代管上傳服務。

目前完成的功能為 Google OAuth 授權及頻道連線檢查，上傳與排程功能仍在建置中。網站說明不代表所有規劃功能已可使用。

帳戶與內容

使用者應僅連接自己擁有或獲合法授權管理的帳戶與頻道，並確認具備發布所選影片、音訊、圖片及文字的必要權利。

發布前，使用者應確認目標頻道、影片內容、標題、說明、公開狀態、適用的觀眾設定、時區及排程時間。授權資料應妥善保存在本機，不應公開分享。

第三方平台

使用本工具操作 YouTube 時，同樣須遵守 YouTube 服務條款與適用的 Google API 政策。工具與 Google、YouTube 沒有官方隸屬或背書關係。

運作限制

工具仍在開發，運作可能受網路、API 配額、授權失效、帳戶限制及 YouTube 的處理時間影響。請保留原始影片，並在 YouTube Studio 確認實際上傳與發布狀態。

切換 OAuth 正式模式不代表取得永久存取權。使用者可隨時撤銷授權，Google 也可能依其政策要求重新登入或授權。

隱私與停止使用

資料處理方式載於隱私權政策。使用者可停止執行本機工具、撤銷 Google 授權並刪除本機設定資料，以停止使用。

更新與聯絡

功能或使用條件變更時會更新此頁。問題請透過 GitHub Issues 聯絡維護者。
