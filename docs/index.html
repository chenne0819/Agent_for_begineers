Agent 課程發布助手是供頻道擁有者自用的工具，設計用途是連接自己的 YouTube 頻道，並將完成的課程影片上傳、安排發布時間。

目前已完成 Google OAuth 授權與頻道連線檢查，上傳及排程流程仍在建置中。此網站提供工具與資料使用說明，不會在網頁上要求登入或接收影片。

工具如何運作

01

由你授權自己的頻道

本機程式開啟 Google 官方授權頁，由你選擇帳戶與頻道、同意所需權限。

02

確認連接的頻道

透過 YouTube Data API 讀取頻道名稱與識別碼，協助確認後續發布的目的地。

03

指定影片與發布安排

上傳流程完成後，由使用者指定影片檔案、標題、說明、公開狀態與發布時間，再交由 YouTube 處理。

為什麼需要 YouTube 權限

  • youtube.readonly：讀取頻道資訊，確認連接對象。
  • youtube.upload：供後續由使用者指定的影片上傳與發布流程使用；Google 同意畫面可能顯示「管理您的 YouTube 影片」。

授權資料保存在本機設定資料夾。這個公開網站及 GitHub repo 不會儲存 OAuth 權杖或用戶端憑證。

詳細資料處理方式請參閱隱私權政策，使用前請閱讀服務條款。
