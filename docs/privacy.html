隱私權政策

生效與更新日期：2026 年 10 月 24 日

本政策適用於「Agent 課程發布助手」本機工具及其說明網站。工具由 GitHub 使用者 chenne0819 維護，供頻道擁有者個人使用。

存取的資料與用途

  • Google OAuth 存取權杖、更新權杖及已同意的權限範圍：用來代表使用者呼叫已授權的 YouTube API，以及在允許的期間內更新存取權杖。
  • YouTube 頻道名稱與識別碼：用來確認連線及預定發布的頻道。
  • 後續啟用上傳功能時，使用者指定的影片、標題、說明、公開狀態與排程時間將傳送至 YouTube，供上傳與發布使用。目前的連線檢查不會上傳影片。

本工具不要求 Google 帳戶密碼；登入與同意授權由 Google 官方頁面處理。工具目前要求 youtube.readonly 與 youtube.upload，不要求存取 Gmail、Google Drive 或聯絡人。

資料儲存與保留

OAuth 憑證與權杖保存在執行工具的電腦上，與公開程式碼分開存放。連線結果包含頻道名稱、識別碼、檢查時間及權限範圍。這些本機資料會保留至使用者刪除或更新。

公開網站不設登入表單、資料庫、廣告或分析追蹤程式。網站由 GitHub Pages 託管，託管服務可能依其隱私權聲明處理連線等技術資訊。

資料傳輸與分享

授權資料透過 Google 官方 OAuth 服務交換，YouTube API 請求透過 HTTPS 傳輸。由使用者授權並指定的資料才會用於相關頻道操作。本工具不出售 Google 使用者資料，不用於廣告投放，也不將這些資料用於自行訓練通用 AI 模型。

若使用者透過 AI 助理執行本機工具，頻道名稱、識別碼、指定的影片資訊及操作結果可能出現在助理對話中，並依該助理服務的資料處理政策處理。OAuth 權杖與用戶端密鑰不應輸出至對話或上傳公開 repo。

Agent 課程發布助手對從 Google API 取得資訊的使用及轉移，遵循 Google API Services User Data Policy，包括 Limited Use 要求。

撤銷授權與刪除資料

  1. 前往 Google 帳戶的第三方連線管理，撤銷本工具的存取權。
  2. 在本機 %LOCALAPPDATA%\AgentCoursePublisher 資料夾中，刪除 token.json 與 connection.json，即可移除儲存的使用者授權及頻道連線資料。
  3. 已上傳 YouTube 的影片需由使用者在 YouTube Studio 管理或刪除；撤銷授權不會自動刪除影片。原始本機影片同樣由使用者自行管理。

政策更新與聯絡

如功能或資料使用方式變動，將更新本頁與日期。問題可透過 GitHub Issues 提出，請勿在公開留言中提供權杖、密碼或其他私人資料。
